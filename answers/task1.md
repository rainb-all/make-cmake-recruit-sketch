# Task 1：从 C 源码到可执行文件

请用自己的语言简要说明下面几个阶段分别做了什么：

1. 预处理：读取`.c`文件后，展开头文件内容、宏定义，并且删除了注释，只是单纯的文本替换，不做词法、语法和语义上的检查，然后输出`.i`文件。
2. 编译：对进行了预处理后的代码进行词法、语法、语义上的检查，翻译为CPU可以看懂的汇编语言，输出`.s`汇编文本文件但依旧是文本，并非二进制。
3. 汇编：调用汇编器，把文本汇编指令翻译成二进制机器码，生成`.o`目标文件。目标文件中已经是包含机器码，但外部函数地址并没有填充，是不能直接运行的半成品。
4. 链接：调用链接器，这里主要是链接函数和全局变量，链接器会在所有的`.o`文件中找寻函数的实现，找到外部函数并补全内存地址，把目标文件和系统库文件合并，打包生成完整的二进制文件，生成可执行文件。

- gcc命令执行中并没有输出信息，`hello.i`和`hello.s`是文本，cat查看是很长的文本内容。`hello.o`和`hello`是二进制文件，打开是乱码。
